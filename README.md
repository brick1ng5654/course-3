# course-3
3 Ветки разработки - Рафаэль Баймухамедов, Александр Аршин, Леонид Пасечный.

## Дисциплины
- Основы машинного обуччения
- Web-программирование
- Базы данных
- Компьютерная графика

## Основы машинного обучения
Темы лабораторных работ:
1. Предобработка данных
2. Решение задачи классификации
3. Решение задачи кластеризации

## Web-программирование
Темы лабораторных работ:
1. Установка и настройка среды разработки и исполнения Web-приложения
2. Создание Web-проекта с использованием системы сборки Maven
3. Построение Web-приложений с использованием технологий сервлетов
4. Интернационализация Web-приложений
5. Построение Web-приложений с использованием JSP
6. Аутентификация и авторизация пользователей Web-приложений
7. Организация передачи данных между запросами пользователей
8. Разработка Web-приложений с использованием GWT (пропущено)
9. Модульное тестирование Web-приложений

## Базы данных
Темы лабораторных работ:
1. Выполнение выборки из таблицы
2. Группировка и агрегирование данных
3. Выполнение запросов по нескольким таблицам
4. Модификация данных
5. Работа с вложенными запросами
6. Обеспечение целостности данных
7. Использование представлений
8. Создание и использование хранимых процедур
9. Создание UDF
10. Управление транзакциями и блокировками
11. Выполнение выборки из таблицы

## Компьютерная графика
Темы лабораторных работ:
1. Исследование математических методов представления и преобразования графических объектов на плоскости и в пространстве
2. Формирования различных кривых с исполььзованием ортогонального проектирования на плоскость визуализации (экране дисплея)
3. Формирования различных поверхностей с использованием ее пространственного разворота и ортогонального проецирования на плоскость при ее визуализации (выводе на экран дисплея)
4. Исследование алгоритмов отсечения отрезков и многоугольников окнами различного вида
5. Исследование алгоритмов выявления видимости сложных сцен
6. Формирования реалистичных изображений с использованием простых моделей освещения одним или двумя точечными источниками
